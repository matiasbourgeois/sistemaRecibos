Instrucciones para el Cliente
1. El cliente abre la app y ve el modal "Licencia Expirada"
2. Abajo del modal aparece su Machine ID
3. Te lo manda por WhatsApp/mail
4. Vos pegás el Machine ID acá arriba y generás el código
5. Le mandás el código al cliente
6. El cliente hace click en "Tengo un código" en el modal
7. Pega el código → Se renueva la licencia 🎉
